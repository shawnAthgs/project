# CyberHelp

CyberHelp is an educational website designed to help people recognize
common online scams and stay safer on the internet.

## About the Project

I created CyberHelp because online scams can affect anyone, especially
people who may not be familiar with common online threats.

The website explains different types of scams and provides information
that can help users recognize suspicious messages, links, requests, and
online behavior.

CyberHelp focuses on cybersecurity education and prevention rather than
assuming that everyone already understands how online scams work.

## Features

- Information about common online scams
- Resources for staying safer online
- Educational information about phishing and other scams
- Scam experience survey
- Contact form for questions and feedback
- Mobile-friendly design
- Dark purple cybersecurity-themed interface

## Scams Covered

CyberHelp currently includes information and/or survey questions related
to scams such as:

- Phishing scams
- Fake check scams
- Emergency scams
- Romance scams
- Ransomware
- Social media account hacking
- Gaming scams
- Verification code scams
